# 記帳

每日記帳 App：12 個支出分類、收入與結餘、固定收支自動記帳、預算提醒、外幣換算，以及年／月／日圖表。

**資料只存在你的手機裡，不會上傳到任何伺服器。** 這個網站只提供 App 本身的程式檔案。

## iPhone 安裝

1. 用 **Safari** 打開 <https://xuyihan92.github.io/ledger/>
2. 按「分享」按鈕，選「加入主畫面」，再按「加入」
3. 之後都從主畫面的「記帳」圖示開啟（離線也能用）

> 在 Safari 分頁裡記的帳，和主畫面 App 裡的是分開的兩份資料。

## 備份

到「設定 → 備份資料」可以把資料存成檔案（可存到「檔案」App、iCloud 雲碟，或傳到 LINE、Email）。換手機時用「從備份檔還原」。Android 版和 iPhone 版的備份檔可以互通。
